# Credit Card Fraud Detection - PBL Demo

This is a complete, modern, responsive web application for a Data Science PBL (Project-Based Learning) project.

## Features
- **Frontend**: HTML5, CSS3, JavaScript, Tailwind CSS (via CDN), Chart.js
- **Backend**: Python Flask, REST API
- **Database**: SQLite (SQLAlchemy)
- **ML Module**: Mocked demonstration of ML algorithms (Logistic Regression, Random Forest, XGBoost) and handling class imbalance.

## Installation Instructions

1. **Open a terminal in VS Code and navigate to this folder:**
   ```bash
   cd C:\Users\THSHIBA\.gemini\antigravity\scratch\cc_fraud_pbl
   ```

2. **Install Python dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Start the backend server (automatically sets up the database):**
   ```bash
   python app.py
   ```

4. **Open your browser and navigate to:**
   `http://127.0.0.1:5000`
