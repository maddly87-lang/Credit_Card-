Credit Card Fraud Detection

An AI-powered web application demonstrating machine learning capabilities for identifying fraudulent financial transactions in real-time.

The Problem

Credit card fraud costs billions annually. The core data science challenge is severe class imbalance (frauds are <0.5% of data), making standard accuracy metrics misleading.

Methodology (SMOTE)

We utilize Synthetic Minority Over-sampling Technique (SMOTE) to synthetically balance the dataset, allowing the models to learn fraud patterns effectively.

Machine Learning Models

Implemented Logistic Regression (baseline), Random Forest (ensemble learning), and XGBoost to predict the probability (Risk Score) of a transaction being fraudulent.

Full-Stack Implementation

Developed a Flask REST API backend, SQLite database, and a responsive HTML/CSS/JS frontend to provide a realistic Banking Security Dashboard experience.
